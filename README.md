# kakeibo

## 企画コンセプト

### 概要

個人がターミナルから日々の収入・支出を手軽に記録し、家計の状況を最低限確認できるローカル完結型CLI家計簿アプリ。

### 対象ユーザー

- 個人利用者
- ターミナル操作に抵抗がない人
- 複雑な家計分析よりも、支出記録を続けることを優先したい人

### 目的

支出・収入を簡単に記録し、保存されたデータから合計や履歴を確認できるようにする。

### 基本方針

- Goで実装するCLIアプリ
- データはローカルのJSONファイルに保存する
- ユーザー登録、クラウド同期、共有機能は持たない
- 機能を必要最小限に絞り、使い方をシンプルに保つ

### MVP（最小実用製品）で扱う機能

- 支出の登録
- 収入の登録
- 登録済み取引の一覧表示
- 収入・支出・収支の合計表示
- JSONファイルへの保存と読み込み

### 今回扱わない機能

- ログイン・複数ユーザー
- 予算管理、予算超過通知
- グラフ・高度な分析
- 編集・削除
- クラウド同期、銀行連携
- 複数通貨対応
